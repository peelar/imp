---
title: Run from a checkout
description: Run the host and build the client from the repository, for development.
---

You need Node 24+ and git. From the root of the repository:

```sh
npm run setup   # about 6 minutes the first time
npm start       # http://localhost:8787
```

Setup installs Bun and Rust when they are missing, puts [Exact](https://github.com/expo/exact) at the commit in `client/exact-rev` where the client looks for it (`tools/exact` two directories above the repository, or `EXACT`), runs Exact's own setup, runs `npm ci` for every workspace and the lint and type tooling, and builds the web client. The host needs all of this because it rebuilds the web client whenever the imp previews an app. Run setup again after a pull that moves `client/exact-rev`.

Open the app, continue with ChatGPT, enter the code it shows, and pick a computer in Settings. `MACHINE=local npm start` instead fixes the agent's computer to a directory on this one, with no isolation.

## Checks

| Command | Where | What it checks |
| --- | --- | --- |
| `npm run check` | root | Lint, the lint policy, formatting and types. CI runs it. |
| `npm test` | root | The host's HTTP API tests, each against its own host with a scripted model. CI runs it. |
| `npx turbo run build --filter=@imp/docs` | root | This documentation site. CI runs it. |
| `bun exact.mjs test web` | `client/` | The client against a host with a fake model. |
| `node scripts/smoke-machine.ts` | `host/` | One machine adapter on its own. |

`npm run dev -w @imp/docs` serves these docs with hot reload.

After you change an app in `client/apps/` by hand, run `node host/scripts/shell.ts` to rewrite its wiring in the client.

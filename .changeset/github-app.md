Imp ships a GitHub app: what needs you on GitHub in one inbox, with the pull requests waiting for your review, your own, what's assigned to you and your unread notifications. Filter it, search it, and mark items done or snooze them; a done item comes back when it changes on GitHub. It reads GitHub with your key named github (notifications need a classic token with the notifications scope), stays current by watching your notifications, and your imp can act on any item from the chat beside it. Its screen is yours to change.

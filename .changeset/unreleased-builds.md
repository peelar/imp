You can try Imp's newest code before it is released: `curl -fsSL https://github.com/peelar/imp/releases/download/unreleased/install-host.sh | IMP_VERSION=unreleased sh` installs the build of `main`, which stays put until you run it again. `IMP_VERSION=v0.14.2` installs a given release.

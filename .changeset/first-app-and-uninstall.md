The onboarding ends by building your first app: describe the GitHub app you want, such as one that shows only the pull requests waiting for your review, and watch your imp build it over Imp's GitHub app. Or skip, and have Imp's as it ships. The GitHub app no longer needs a feature flag. Any app can now be uninstalled from the bar on its page, which deletes it and all its data once you confirm. Todos moved to the App directory; a host that already has Todos keeps it, with its todos.
Confirmations, such as Sign out and Uninstall, now look like the rest of Imp.
Settings has a new Connections section: connect GitHub once with a device code, and the GitHub app, your imp and Backup all use it. Backup moved there, below the connection, and turns on with one click. A host already backing up to GitHub keeps its sign-in.

Your imp can preview the apps it builds on an installed Imp again. Previews used to fail with "no such file or directory … shell/app.contract", because Imp had nothing to build them with. Now the first start after this update sets up those tools by itself, which takes a few minutes and about 6 GB of disk. Until it finishes, the imp says a preview has to wait.

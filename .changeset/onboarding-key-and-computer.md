Onboarding is now a short wizard. It takes an OpenAI-compatible API key as well as a ChatGPT sign-in, then asks for your imp's computer: Imp cloud, a computer of yours, or skip them and use a container on the machine Imp runs on. To set up a computer of yours, Imp gives you a prompt to copy into a coding agent on that computer, instead of commands and a policy to paste by hand. Opening Imp without a computer no longer shows an empty Computer page over the home screen and blocks every click.
